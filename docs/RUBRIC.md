# 评分表

把"达到 MC 1.0 的 80%"变成一个可以逐项打分的数字。
每个子项按 0.5 分为最小单位。**只给在游戏里生存模式下能真正触发的行为算分，代码存在不算。**
任何一类若会崩溃或损坏存档，该类计 0 分。

**三项闸门测试**，任一不过总分封顶 60：
1. **第一夜** —— 出生 → 徒手打木 → 合成台+工具 → 搭掩体 → 熬过有怪的一夜
2. **下矿** —— 下到 Y<16，火把照明找到钻石，躲开岩浆，活着回来
3. **存读** —— 退出重进，世界/背包/容器内容/时间完全还原

## 分数标尺

- **60** = "一个体素游戏"：地形、挖掘、合成、一种敌对生物、昼夜、存档
- **70** = "一个类 MC 游戏"：群系、洞穴、正确矿物带、完整工具树、饥饿、5 种生物、流体、箱子、音效
- **80** = "缺了终局的 1.0 复刻"：以上加苦力怕爆坑、下界、床、农业、红石基础、平滑光照、
  环境音、天气、约 120 条配方、约 60 种方块
- **90** = 再加附魔、酿造、经验、末地与末影龙、村庄、矿车、完整红石
- **100** = 成就、统计、地图、唱片、画作、全部 110 种方块、多人

**本项目按 90+ 规划**，里程碑排序保证 M14 完成时越过 80 分线，之后继续推下界、末地、多人。
砍掉的内容见 [DEVIATIONS.md](DEVIATIONS.md)。
