# 评分表

把"达到 MC 1.0 的 80%"变成一个可以逐项打分的数字。
每个子项按 0.5 分为最小单位。**只给在游戏里生存模式下能真正触发的行为算分，代码存在不算。**
任何一类若会崩溃或损坏存档，该类计 0 分。

**三项闸门测试**，任一不过总分封顶 60：
1. **第一夜** —— 出生 → 徒手打木 → 合成台+工具 → 搭掩体 → 熬过有怪的一夜
2. **下矿** —— 下到 Y<16，火把照明找到钻石，躲开岩浆，活着回来
3. **存读** —— 退出重进，世界/背包/容器内容/时间完全还原

## 分数标尺

- **60** = "一个体素游戏"：地形、挖掘、合成、一种敌对生物、昼夜、存档
- **70** = "一个类 MC 游戏"：群系、洞穴、正确矿物带、完整工具树、饥饿、5 种生物、流体、箱子、音效
- **80** = "缺了终局的 1.0 复刻"：以上加苦力怕爆坑、下界、床、农业、红石基础、平滑光照、
  环境音、天气、约 120 条配方、约 60 种方块
- **90** = 再加附魔、酿造、经验、末地与末影龙、村庄、矿车、完整红石
- **100** = 成就、统计、地图、唱片、画作、全部 110 种方块、多人

**本项目按 90+ 规划**，里程碑排序保证 M14 完成时越过 80 分线，之后继续推下界、末地、多人。
砍掉的内容见 [DEVIATIONS.md](DEVIATIONS.md)。

### 2026-08-31 的这一次打分怎么来的

**扣分的九处**，每一处都是"游戏里真的没有"，不是"代码里没写完"：

| 扣了 | 哪一项 | 实情 |
|---:|---|---|
| −0.5 | 结构 | 只有要塞。村庄、废矿、下界要塞、地牢都没有 |
| −1 | 手持渲染 | 第一人称手里不画东西 |
| −0.5 | 水下 | 泡在水里没有蓝色滤镜与雾 |
| −1 | 难度 | 只有普通难度，不可选 |
| −0.25 | 生物 roster | 11/15。缺史莱姆、岩浆怪、僵尸猪人、蠹虫、狼、豹猫、乌贼、雪傀儡 |
| −1 | 近战暴击 | 下落中攻击不加伤害 |
| −1 | 创造模式 | 没有 |
| −0.5 | 交通与家具 | 矿车与船只有物品，没有实体 |
| −0.75 | 下界内容 | 有恶魂，但没有下界要塞、僵尸猪人、烈焰人 |
| −0.5 | 成就 | 没有 |

**三项闸门**：

| 闸门 | 状态 | 依据 |
|---|---|---|
| ① 第一夜 | ✅ | `tools/first-night-check.mjs`，M12 通过 |
| ② 下矿 | ✅ | `tools/mine-check.mjs`，连跑三次全绿。查到并修掉一个**真的游戏 bug**：站在岩浆池底上时 `floor(y)` 落到池底那块石头上，人整个泡在岩浆里却不再掉血（见下） |
| ③ 存读 | ✅ | `tools/persist-check.mjs`，M9 通过 |

**闸门②沿路查出来的一个真 bug**：`tickVitals` 判"在不在岩浆里"只看
`floor(player.y)` 那一格。而玩家站在岩浆池底上时，脚下有实心方块托着，
y 会停在 `11.9999996` —— floor 得到 11，也就是**池底那块石头**，
于是判定为假，人整个泡在岩浆里却不再掉血。

MC 的判据是**碰撞盒与流体相交**。现在按身高扫一遍所占的格子
（`bodyHas`），语义相同而代价只有两三次查表。火与灭火同理。

诊断信息本身也修了：`pos` 原来只打 `feet=`（floor 那一格），
与伤害判定看的东西对不上 —— 失败信息会指向错的方向。
现在多打一个 `body=`，就是判定实际扫的那一串。

顺带修掉三处**验收脚本自己的错**（都不是游戏的问题）：
泡岩浆的时长按帧算（4fps 的容器里 70 帧 = 17 秒，必死）、
正则的反斜杠被模板字符串吃掉、以及开着自然刷怪让这一项随机失败。

**性能那三条**（M17 的验收标准之一）：服务端每刻 3.39ms（线 25ms）✅、
多人指令往返 50.5ms（线 100ms）✅、三分钟堆漂移 ×0.90 ✅；
客户端帧率与十分钟内存**都要在真显卡上补测**（容器是软件渲染，
4fps，十分钟那一档标签页会中途崩掉）。

**离 100 还差的**：成就、统计、地图、唱片、画作、村庄、矿车与船的实体、
创造模式、剩下四种生物、下界要塞那一套。都是明确的、可以逐项加的东西，
没有任何一项需要动架构。

## 2026-08-31 第二次打分（复核之后）：**92**

M17 打完 93 分之后，起了一轮**六个方向的并发审计**（附魔的全部搬运路径、
多维度状态、多人状态、存档缺口、1.0 内容对账、客户端渲染跟进），
每条发现要过三个独立复核人、两票才留。查出三十多处问题，绝大多数是同一个形状：

> **新特性只接进了一部分既有路径，剩下的静默丢弃。**
> 不报错、测试全绿、只有玩家会发现东西没了。

### 分数为什么从 93 降到 92

不是代码变差了 —— 是**原来的打分有两处虚高**，审计把它们照出来了：

| 改动 | 原分 | 现分 | 为什么 |
|---|---:|---:|---|
| 弓箭 | 1 | **0.5** | 弓有物品和贴图，但**没有合成配方**，也没有任何玩家射箭的路径。只有骷髅会射。原来按"弓箭做了"给满分，实际玩家碰不到 |
| 酿造 | 1.5 | **1** | 酿得出各种药水，但**喝不了**：右键药水没有任何反应，玻璃瓶也灌不了水。酿造的出口整段没接上 |

"代码存在不算分，游戏里能触发才算"是这张表第一行就写着的规矩。
这两处是没照着自己的规矩打分。

### 这一轮真正修掉的（每条都带回归测试，且都确认过"退回旧代码会红"）

**附魔**——原来它对玩法**完全没有作用**（`enchantLevel()` 全仓库零调用者）：
- 锋利/亡灵杀手/节肢杀手、火焰附加、击退、抢夺、保护系、效率、
  精准采集、时运、耐久、水下呼吸，全部接进了实际计算。
- 附魔在物品栏里挪一格就会消失（`copyStack` 只搬 id/count/damage）——
  五处搬运路径全修。
- **附魔台附完魔按一下 Esc，附魔连同等级一起没了**（窗口那份旧快照把方块
  实体整个盖掉）—— 这是整条附魔链最致命的一处，玩家无论怎么操作都拿不到
  附了魔的装备。
- 界面上现在看得见了：紫色流光 + 悬停提示。

**多维度**——实体这一侧有十来处写死了主世界：
- 在下界挖的矿掉进主世界、被主世界的人捡走；末影龙挂在主世界出生点的天上；
  下界炸一发 TNT 把主世界同坐标的玩家炸死；在下界死掉重生还留在下界的
  岩石里反复死；下界几乎刷不出怪（落脚点判定读的是主世界的地形）。
- 存档层完全不知道维度：下界与主世界的区块写到**同一个 region 文件**上。

**多人**——单人完全掩盖的一类：
- 两个人开同一个箱子 = 稳定复制物品（实测凭空多出 64 颗钻石）。
- `player.dat` 只有一份：每个登录的人都会套上同一份背包。
- 客户端把玩家名写死成"玩家"，所有人共用一份档。
- 断线重连回滚到开服那一刻；手上抓着的东西凭空消失。

**存档**——末影龙打过了没不进存档（退出重进又是一条龙，一颗龙蛋 + 12000 经验
可以无限刷）；读回来的生物维度全变成主世界。

### 还没修的（诚实清单）

| 严重度 | 是什么 |
|---|---|
| 高 | **药水喝不了、玻璃瓶灌不了水** —— 酿造的出口没接上 |
| 中 | 挖萤石掉萤石方块而不是萤石粉，萤石粉全游戏拿不到（酿造二级药水的关键材料） |
| 中 | 发酵蛛眼的腐化表与 1.0 对不上；水瓶 + 发酵蛛眼酿不出虚弱药水 |
| 中 | 酿造台不校验瓶位放的是不是药水，玻璃瓶会被吃掉材料并改坏 damage |
| 中 | 附魔扣完等级不把新等级发给客户端，HUD 上的数字是旧的 |
| 中 | 酿造的 20 秒里不发进度包，进度条纹丝不动 |
| 中 | 客户端画雨不看维度，主世界下雨时末地天上也在下 |
| 低 | 盔甲的附魔性套用了工具的数值 |
| 低 | 末地传送门框架从不随机预填末影之眼 |
| 低 | 玩家不能用弓（见上） |

这份清单是那轮审计的原始产出，**其中一部分还没有逐条复核过**
（复核那一步跑到一半撞上了用量上限）。当成"待查的线索"而不是"确定的缺陷"来用。
